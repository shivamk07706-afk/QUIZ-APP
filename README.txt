SHIVAM QUIZ — FULL PROJECT

Files: index.html, style.css, script.js, question_bank.js

HOW TO OPEN:
1. Extract this ZIP into a new folder.
2. In VS Code choose File > Open Folder and select the extracted folder.
3. Check all four files are together in the Explorer.
4. Open index.html and click Go Live (if Live Server is installed), or open index.html in Chrome.
5. Choose a subject to begin.

IMPORTANT: Do not paste question_bank.js content into index.html or script.js. Keep it as its own file.
